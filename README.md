# 🧠 MindPulse AI

MindPulse AI is a machine learning powered web application that predicts a student's mental health score based on social media usage, academic routine, lifestyle habits, and stress level.

The project combines a trained machine learning model, FastAPI backend, and an interactive HTML/CSS/JavaScript frontend to create a complete end-to-end ML application.
